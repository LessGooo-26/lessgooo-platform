# First Codex Task After Bootstrap

Read `AGENTS.md` and `docs/index.md` before doing anything else.

Then inspect this repository and produce a report called:

`docs/plans/active/repository-assessment.md`

Do NOT redesign or implement the application yet.

The assessment must contain:

1. Existing technology stack.
2. Existing directory structure.
3. Existing package scripts.
4. Existing pages/features.
5. Existing Git/GitHub configuration.
6. Existing tests.
7. Existing deployment configuration.
8. Conflicts with `ARCHITECTURE.md` or accepted ADRs.
9. Security concerns.
10. Missing information that belongs in `docs/UNKNOWN.md`.
11. Recommended MVP sequence.
12. Exact validation commands that currently work.

Rules:
- do not invent LESSGOOO facts;
- do not delete existing code;
- do not install dependencies;
- do not change application architecture;
- cite repository files in the assessment.
