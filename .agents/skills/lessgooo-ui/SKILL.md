# LESSGOOO UI Skill

Before changing UI:

1. Read `docs/design/brand.md`.
2. Read relevant product/program content.
3. Reuse existing design-system components.
4. Design mobile-first.
5. Keep interfaces usable for low digital-literacy users.
6. Avoid unnecessary heavy media.
7. Maintain accessible labels and keyboard behavior.
8. Do not invent missing institutional content.
9. Verify mobile, tablet and desktop layouts where practical.
