# LESSGOOO Deployment Skill

1. Read `docs/engineering/deployment.md`.
2. Read accepted ADRs.
3. Inspect package scripts before inventing commands.
4. Keep secrets out of source and logs.
5. Validate before deployment.
6. Treat GitHub Pages as static hosting.
7. Do not introduce backend assumptions without an accepted ADR.
