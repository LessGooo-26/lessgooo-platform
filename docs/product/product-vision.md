# LESSGOOO Digital Product Vision

The LESSGOOO platform should become the digital operating and public
communication layer for the academy.

It should eventually support several surfaces:

1. Public LESSGOOO website.
2. Learner experience.
3. Parent/guardian experience.
4. Staff/instructor experience.
5. Administration experience.

The first implementation may intentionally cover only the public website.

## Product principles

- Cameroon-aware.
- French/English-ready.
- Mobile-first.
- Simple for inexperienced users.
- Low-bandwidth-conscious.
- Secure by design.
- Clear institutional truth.
- No invented claims.
- Modular enough to add authenticated services later.
