# Campus workspace interface — 2026-09-23

CONFIRMED owner request: take useful interface ideas from Microsoft Edge/Microsoft productivity tools and Google for LESSGOOO. Interpret this as navigation and productivity design, preserving LESSGOOO's logo, language, content and accepted local-demo boundaries.

## Selected interaction patterns

- A persistent, clearly labelled search entry and an application launcher grid.
- Grouped navigation for learning, creation/organization and support.
- Up to six pinned section shortcuts and four recent sections, kept per demo persona on this browser. Store only section IDs, never records, documents or search text. Storage failure must not prevent use during the visit.
- A calmer home workspace with visible actions, useful descriptions and recent sections. Keep the parent's existing overview and the current homework workflow.
- Search tools and permitted lessons locally, open exact lesson results, and pass a search to the existing campus-wide search for files/notes/homework. This is not web search or an AI assistant.
- Keyboard access (Ctrl/Cmd+K, Escape, standard Tab/Enter), focus restoration, reduced motion and responsive layouts.

## Boundaries

Navigation visibility follows existing personas and is not authentication. No new integration, Microsoft/Google affiliation, copied logo, external account access, domain rule or production permission is implied. Existing lessons, submissions, notes, gallery backgrounds and uploaded files stay intact. Personalization remains local browser preference data.

## Design references

Reviewed official material: [Microsoft Edge Workspaces](https://support.microsoft.com/en-us/edge/getting-started-with-microsoft-edge-workspaces) for organizing activity contexts; [Google Workspace](https://workspace.google.com/) for a unified set of recognizable tools. These inspire original LESSGOOO components rather than imported artwork or a pixel-for-pixel replica.
