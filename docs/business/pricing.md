# Pricing Rules

Status: CONTROLLED DATA

Prices must never be guessed.

Program pricing can change because of:
- cohort;
- promotion;
- duration;
- learner category;
- registration fee;
- scholarship/discount;
- campaign period.

Use structured program/pricing data.

If the current price is not confirmed:
- show "Contact LESSGOOO for current fees", or
- omit the price.

Never copy a historical promotional amount into a current offer without
confirmation.
