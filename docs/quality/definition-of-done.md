# Definition of Done

A feature is done when:

- requested behavior exists;
- relevant source-of-truth documentation was consulted;
- no institutional facts were invented;
- existing architecture was respected or an ADR was added;
- relevant tests pass;
- lint/typecheck/build pass when configured;
- security/privacy implications were considered;
- UI is usable at relevant viewport sizes;
- documentation is updated when confirmed behavior changed;
- unresolved assumptions are reported.
