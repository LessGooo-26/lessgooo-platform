# LESSGOOO Terminology

## Learner
Generic person receiving training.

## Student
Learner enrolled in a structured program or course.

## Parent / Guardian
Responsible adult associated with a minor learner.

## Instructor / Teacher
Staff member authorized to deliver training.

## Staff
Any authorized LESSGOOO worker. Staff does NOT mean teacher.

## Administrator
Staff member with administrative responsibilities.

## Program
A structured training offering composed of one or more courses/modules.

## Course / Module
A defined instructional subject or unit.

## Cohort
Group of learners progressing through a program together.

## Session
A specific class meeting.

## Enrollment
Formal association between a learner and a program/cohort.

## Academy
The LESSGOOO learning/training organization.

When code requires a more precise definition, update this file and the relevant
domain model rather than inventing terminology independently.
