# Mission, Vision and Values

Status: WORKING SOURCE OF TRUTH
Last reviewed: 2026-08-29

## Mission

Make practical technology and modern professional skills understandable and
accessible to learners in Cameroon through hands-on learning, real equipment,
real software and continuous practice.

## Vision

Develop learners who understand technology deeply enough to use it, build with
it, troubleshoot it and apply it to real work rather than merely memorizing
definitions.

## Educational values

- Practical before decorative.
- Explain WHY, not only WHAT.
- Learn by doing.
- Continuous learning.
- Build confidence through competence.
- Teach foundations before abstraction.
- Use accessible examples and local context.
- Do not exaggerate outcomes.
- Respect learners, parents and staff.
- Keep institutional claims factual.
